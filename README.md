# Calculator Project (Python)

This calculator originally started as a little Python exercise, but it then turned into a fun way for me to practice clean logic, user interaction, and loops. It runs entirely in the terminal, supports basic arithmetic, and shows an ASCII-art calculator when the program runs. It's nothing that fancy, just a little project to sharpen my fundamentals, making them better.

---

## What It Does

- Performs addition, subtraction, multiplication, and division
- Lets you keep calculating using your previous result
- Restarts completely clean without having to restart the program
- Shows a ASCII calculator logo on start
- The code is kept real simple and easy to follow

---

## Project Structure

```
Calculator_Project/
│
├─ Calculator_Project.py               # Main calculator logic
└─ Calculator_project_Art.py           # ASCII art logo
```

It's really simple and easy to follow.

---

## How To Run It

Make sure both of the files are in the same folder, then run:

```
Calculator_Project.py
```

It'll first greet you with the ASCII calculator logo and walk you through every step.
